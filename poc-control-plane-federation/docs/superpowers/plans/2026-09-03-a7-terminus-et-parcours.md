> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline, un seul écrivain — le mode de défaillance « narration prématurée » des sous-agents est mesuré et cher, mémoire g2-axe-qui-deploie). **Goal:** une application parcourt `dev → rec → int → homol → prod` en cinq PR ouvertes **sous l'identité de forge du demandeur** (token nominatif), mergées et portées par alice/alice/bob/carol/oscar, appliquées sur la 10.15 (quatre paliers) puis sur le terminus `wm-mock-prod` (voie déclarée, ticket accordé, porte `apim-operator-prod`) — l'API promue au terminus par archive (même GUID), l'équipe de cloisonnement lue dans Git sous une déclaration de déployeur, `change_ref`/`pv_ref` transportés par la demande ; contre-épreuves `ITSM_NOT_APPROVED`, `PAYLOAD_PERIME`, `API_NOT_PROMOTED`/`API_INACTIVE` au terminus, `REQUESTER_UNKNOWN`/`GATE_REFS_REQUIRED`/`TOKEN_ALTERE` à la demande ; preuves hors ligne (fixture A6 + stub forge à journal + shim git + mutations, stub Vault d'A3) et par builds réels.

## Global Constraints (copiées de la spec)

- **Aucun `job.xml` porteur de logique** ; un paramètre posé par `properties()` n'exige aucune re-pose mais un **build d'amorçage** avant tout `buildWithParameters` (SECURITY-170).
- **Rien n'est poussé avant le dernier refus** ; refus = `REFUS: <TAG> : <phrase>` (stderr rc 2 pour les demandes ; stdout rc 1 pour la garde A3 et la porte A4).
- **Ordre des demandes** = forme → chaîne (`env_chain`, validée, épinglée par l'appelant) → refs (`REF_INVALIDE`, `GATE_REFS_REQUIRED`) → identité (`forge_login` seulement si token humain ; `REQUESTER_UNKNOWN` sous `fourEyes` sans humain) → clone → contrat/fusion → PR ouverte relue AVANT le push (`REPLI_EN_COURS` quel que soit l'auteur ; `PR_D_AUTRUI` si auteur ≠ identité du pousseur) → commit (`Demande-Par:`) → push par `GIT_ASKPASS` (jamais d'URL avec credential, jamais d'argv) → `POST /pulls` sous le token humain → plan sous `GITEA_TOKEN`, **après `unset` du token humain**.
- **Le token humain** : lu de `FORGE_TOKEN` (env) ou `FORGE_TOKEN_FILE`, copié dans un fichier 0600 du `mktemp`, `unset FORGE_TOKEN` avant toute autre ligne ; jamais dans un journal (l'erreur de push est filtrée du token) ; scopes annoncés `read:user + write:repository`.

- [x] **Étape 1 — la lib** `scripts/lib/forge-identity.sh` :

```bash
#!/usr/bin/env bash
# scripts/lib/forge-identity.sh — A7 : l'identité de FORGE d'une demande. Le token
# nominatif (formulaire) est la seule preuve d'identité humaine que ce lab tient ;
# son porteur EST l'auteur de la PR, c'est lui que la porte à quatre yeux (A4)
# confronte au mergeur. Token par FICHIER (jamais argv, jamais URL) ; login borné.
forge_login(){ # <api-base> <token-file> → login sur stdout
  local api="$1" tf="$2" hc body login
  [ -s "$tf" ] || { echo "REFUS: FORGE_TOKEN_INVALIDE : fichier de token vide" >&2; return 2; }
  { printf 'Authorization: token '; tr -d '\r\n' < "$tf"; printf '\n'; } > "${tf}.hdr" || return 1
  hc=$(curl -sS --max-time 20 -H @"${tf}.hdr" -o "${tf}.user" -w '%{http_code}' "${api}/user" 2>"${tf}.err") || { rm -f "${tf}.hdr"; echo "ERREUR: identité de forge invérifiable (réseau) : $(head -c 120 "${tf}.err" | tr '\n' ' ')" >&2; return 1; }
  rm -f "${tf}.hdr"
  case "$hc" in
    200) ;;
    401) echo "REFUS: FORGE_TOKEN_INVALIDE : la forge refuse ce token (HTTP 401) — token révoqué ou mal collé" >&2; return 2 ;;
    403) echo "REFUS: FORGE_SCOPE_INSUFFISANT : le token ne peut pas lire son propre profil (HTTP 403) — il doit porter le scope read:user (et write:repository pour pousser)" >&2; return 2 ;;
    *)   echo "ERREUR: identité de forge invérifiable (GET /user → HTTP $hc)" >&2; return 1 ;;
  esac
  login=$(python3 -c 'import json,sys
try: print(str((json.load(open(sys.argv[1])) or {}).get("login") or ""))
except Exception: print("")' "${tf}.user" 2>/dev/null); rm -f "${tf}.user"
  [ -n "$login" ] || { echo "ERREUR: identité de forge invérifiable (réponse sans login)" >&2; return 1; }
  printf '%s' "$login" | grep -Eq '^[A-Za-z0-9._-]+$' || { echo "REFUS: FORGE_LOGIN_INVALIDE : login '$login' hors de [A-Za-z0-9._-] — il entrerait dans un corps de PR et un trailer" >&2; return 2; }
  printf '%s' "$login"
}
forge_is_service(){ local l; for l in $2; do [ "$l" = "$1" ] && return 0; done; return 1; }
forge_askpass(){ # <dir> <login> <token-file> → chemin du script GIT_ASKPASS
  local f="$1/askpass"
  printf '#!/bin/sh\ncase "$1" in Username*) printf %%s "%s" ;; *) tr -d "\\r\\n" < "%s" ;; esac\n' "$2" "$3" > "$f" && chmod 700 "$f" && printf '%s' "$f"
}
```
