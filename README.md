# stoa-labs

Experimental labs / R&D for the STOA Platform.

This repository hosts spikes, prototypes, and proof-of-concept work that is not
yet part of the production STOA platform. Code here is intentionally exploratory
and may be unstable, undocumented, or short-lived.

## Scope

- Prototypes and technical spikes
- Throwaway experiments and benchmarks
- Early-stage ideas before they graduate to a production repo

> ⚠️ Nothing in this repo is production-ready or supported. Graduated work moves
> to the appropriate STOA repository (`stoa`, `stoa-infra`, etc.).
